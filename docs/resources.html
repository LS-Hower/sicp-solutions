3 如何运行代码：一些 Scheme 实现🔗

  • Racket ：工具链成熟，其中就包含集成开发环境 DrRacket。本项目也使用了 Racket 工具链和语言。

  • MIT/GNU Scheme ：最为正统，是书中所使用的 Scheme 实现。（安装难度稍大。）

  • Chez Scheme ：一般认为是最快、最稳定的 Scheme 实现之一。

  • GNU Guile ：便于嵌入其他程序作为扩展，是 GNU 各种软件项目的首选。

  • try.scheme.org ：Scheme 官网的在线交互式解释器，可以快速地测试少量代码片段。

Scheme 资料汇集：Scheme 官方网站 一节中也提到，Scheme 官网上有 Scheme 实现列表。

各种 Scheme 实现都基本遵循（至少一些版本的）Scheme 标准，所以都能运行书中绝大多数代码。虽然偶尔会有不同行为，但这类问题一般都不难解决。

例如，在 Racket 语言中， cons 所生成的序对是不可变的，不能对它们使用 set-car! 和 set-cdr! 。要解决这一问题，可以：

  • 使用 Racket 里专门的可变序对类型 。

  • 用更简单的方法：在源代码首行用 #lang r5rs 指定使用 Racket 中 Scheme 的 R5RS 方言 ，这样书上的 set-car! 和 set-cdr! 就都可以正常使用了。

补充的 Lisp 知识 页面对序对不可变性也有更详细的讲解。
